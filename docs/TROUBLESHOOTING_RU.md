# Диагностика ошибок

| Симптом | Причина / действие |
|:--|:--|
| FireCalc не появляется в списке модулей | Проверьте `FireCalc.rndesc`: версия из четырёх числовых частей, обязательный `Copyright`, `RequiredAPIVersion=2.50`, `PluginType=Net8`; откройте `AecApp.log`. |
| Ошибки `FileStream`, `StreamWriter` | Проверьте `using System.IO;` в `ExcelExporter.cs`. В актуальной исходной версии исправлено. |
| `List<int>` не содержит `Length` | Используйте `pipes.Count` для списка; ошибка ранее исправлена. |
| Не находится `RengaCOMAPI.tlb` или PluginUtility | Выполните `PREPARE_SDK.ps1` с официальным ZIP SDK. |
| Трубы найдены, объёмы нулевые | Проверьте доступность внутреннего диаметра в `PipeStyleId`, а также длину. Используйте диагностический статус. |
| В свойствах Renga объём `0,00` | Может быть округление отображения до двух знаков; спецификацию настройте с нужной точностью или смотрите объём в литрах. |
| Граф показывает две компоненты, а IFC — одну | Маршрутные концы соединены через оборудование; текущая версия не всегда объединяет их через порты/внутреннюю гидравлику насосов. |
| `InvalidCastException` в чтении порта | Ошибка чтения конкретного объекта Renga API; соберите предупреждение, ID и AecApp.log, не предполагайте, что граф полон. |
| Нет ID второго насоса | Выберите его строку в таблице портов и нажмите «Добавить ID насоса из строки». В поле IDs должен появиться список. |
| Расчёт пути/дерева блокируется | Кольцо, неполный граф, несколько источников, неизвестные Q либо альтернативные пути — это ожидаемая защита. |
| `Export XLSX` недоступен | Пересчитайте после изменения исходных данных — старые результаты недействительны. |

При багрепорте укажите версии Renga и FireCalc, точные шаги, текст ошибки и наличие/отсутствие модификаций модели. **Не публикуйте** в открытых issue клиентские `.rnp`, `.ifc`, Excel и ключи лицензии.
