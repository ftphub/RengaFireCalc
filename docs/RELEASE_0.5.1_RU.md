# Renga FireCalc v0.5.1 — source release

**Тип релиза:** source-only / инженерный прототип. **Платформа:** Windows x64, Renga Professional 9.3, API 2.50, .NET 8.

В версии 0.5.1 добавлена удобная работа с ID объектов и маршрутов без ручного копирования из Renga. Можно выделить строку таблицы и скопировать идентификаторы, передать начальный/конечный объект в поиск пути, выбрать предполагаемый источник и добавить ID выбранных насосов в сценарий. Подсказки к формулам и полям, справочник обозначений и диагностика портов сохраняются из 0.5.0.

**Основные возможности:** чтение труб и объёмов из BIM; запись пользовательского свойства в Renga; оценка запасов воды/пенообразователя; ручная гидравлика по участкам; XLSX/CSV; диагностика инженерных маршрутов и портов.

**Ограничения:** режим работы насосов пока является декларацией; расчёт Q–H, физической увязки сложной сети и нормативный подбор Кт отсутствуют. Примеры ЭФЭР не подменяют расчётную экспертизу. Плагины и SDK третьих сторон не включены.

**Установка:** получить официальный SDK Renga, выполнить `PREPARE_SDK.ps1`, собрать Visual Studio Release/x64, перенести всю папку `_build\FireCalc` в Plugins. Подробности в `docs/INSTALL_RU.md`.

> **Данный GitHub source-release не содержит скомпилированного Windows-плагина.** Не отмечайте «готовый бинарный релиз», пока он не будет построен, установлен и проверен отдельно.
