# Roadmap — план развития, не реализованные обещания

- [ ] Объединение маршрутов через типизированные порты насосов/арматуры/фитингов с детальным отчётом о неоднозначности.
- [ ] Выбор источника и потребителей прямо по именам и выделению в 3D вместо ручного ввода ID.
- [ ] Явное назначение насосам рабочего/резервного режима и сторон всасывания/нагнетания.
- [ ] Q–H характеристики насосов, проверка рабочего режима и совместной работы на подтверждённых исходных данных.
- [ ] Отдельные справочники материалов/арматуры/Кт с источниками и диапазонами применимости.
- [ ] Гидравлический расчёт по физической сети с учётом местных сопротивлений и данных потребителей.
- [ ] Автоматизированные отчёты по каждой подсистеме и синхронизация с шаблонами спецификаций Renga.
- [ ] Regression-испытания на открытых синтетических BIM-моделях, без данных заказчика.
- [ ] Улучшения доступности UI для 720p / масштабирования / клавиатуры.

**Не включено сейчас:** подтверждённый нормативный расчёт и выпуск рабочей документации без участия инженера.
