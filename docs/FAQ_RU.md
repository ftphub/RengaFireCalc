# Частые вопросы

**Нужен ли Excel?** Нет для создания файла `.xlsx`; Excel или совместимое ПО понадобится для его удобного просмотра.

**Можно ли выбирать все трубы сразу?** Нет. Ручная гидравлика требует подтверждённой последовательной трассы.

**Почему маршруты разделены на две компоненты?** Алгоритм смотрит на концы `Route`; соединённые через насосы/фитинги линии могут не объединяться в одну сеть. Диагностика портов даёт дополнительные сведения, но не гарантирует физическую проходимость.

**Можно ли поставить два насоса в сценарий?** Да, добавляя по одному ID из таблицы портов. Это лишь фиксация сценария, не гидравлический подбор.

**Где скачать готовую DLL?** Текущий репозиторий содержит исходники. Для локальной компиляции нужен официальный SDK Renga. Бинарный релиз можно публиковать только после сборки и испытаний.

**Можно ли открывать репозиторий для всех?** Рекомендован приватный доступ до проверки прав на клиентские примеры и скриншоты.
