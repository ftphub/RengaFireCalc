# Основные обозначения и расчётные зависимости

Приведены **описательные** формулы используемого расчётного прототипа, а не нормативно утверждённая методика проектирования пожаротушения. Подробности из программного справочника и исторических тестов — в `FireCalc.Plugin/HelpCatalog.cs` и `docs/archive/FORMULAS_0.5.md`.

| Обозначение | Смысл | Единицы / правило |
|:--|:--|:--|
| `L` | длина участка трубопровода из BIM | м |
| `Dвн` | внутренний диаметр из стиля трубы | мм |
| `Vтр` | геометрический объём участка | `π · (Dвн / 1000)² · L / 4`, м³ |
| `Q` | заданный расход через участок | л/с |
| `v` | скорость течения | `4(Q/1000) / (π(Dвн/1000)²)`, м/с |
| `Кт` | табличный коэффициент гидравлического сопротивления в применяемой методике | значение подбирает инженер; нельзя переносить произвольно |
| `Δh` | линейные потери в расчёте по Кт | в исходной методике `Q² · L / (100 · Кт)` МПа с дальнейшим пересчётом в метры |
| `Wраб` | рабочий запас пенообразователя | м³, по расходу, времени и концентрации |
| `Wрез` | резервный запас пенообразователя | м³, задаётся методикой |
| `Wкомп` | запас на погрешность дозирования | м³ |
| `Wисп` | запас на испытания | м³ |
| `Wтр` | вместимость **расчётной подсистемы труб ПО** | м³; не весь сухотруб |
| `Wmin` | минимум в баке / остаточный запас | м³ |
| `W` | общий расчётный запас пенообразователя | `Wраб + Wрез + Wкомп + Wисп + Wтр + Wmin`, м³ |

> [!WARNING]
> Исходные PDF и Excel ЭФЭР не полностью совпадают по суммам и округлениям. Демопримеры не являются подтверждением корректности инженерного расчёта.

Для потерь арматуры и оборудования не следует делать вывод о сопротивлении только на основании 3D-геометрии. Нужны характеристики и подтверждённые данные производителя.
