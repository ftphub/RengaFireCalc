# Контроль расчётов и расхождения с РУП.Т

Состояние: v0.1 / 20.10.2026. Методика **не аттестована**; воспроизводятся формулы переданного заказчиком Excel.

## Использованные Excel-формулы (Лист1)

| Excel | Смысл | Вычисление |
|---|---|---|
| L6 | вода на тушение, м³ | 60 × L1 × L2 × (1 − L3×0,01) / 1000 |
| L8 | вода на охлаждение, м³ | 60 × L4 × L5 / 1000 |
| L9 | общий запас воды | L6 + L8 |
| L16 | рабочий запас ПО | 60 × L1 × L2 × L3 × 0,01 / 1000 |
| L18 | резерв ПО | L16 |
| L20 | поправка дозирования | 0,2 × (L16 + L18) |
| L22 | испытания | 0,1 × L16 |
| L23 | вместимость труб Wтр | **ручное значение** |
| L26 | минимальный уровень бака | ROUND(0,2 × (L16+L18+L20+L22+L23), 3) |
| L27 | общий запас ПО | L16+L18+L20+L22+L23+L26 |

Важно: запас воды с учётом сухотруба — отдельный показатель прототипа, которого **нет** в Excel L9. Он нужен для сравнения с PDF и **не приравнивается** к L9.

## Проверочные примеры из РУП.Т (стр. 21–22)

| Показатель | Окрасочный | Ремонтные |
|---|---:|---:|
| Тушение, мин | 15 | 10 |
| Раствор, л/с | 80 | 80 |
| Концентрация, % | 1 | 1 |
| Охлаждение, мин / л/с | 0 / 0 | 60 / 80 |
| Ручное Wтр, м³ | 0,14 | 0,25 |
| Сухотруб, м³ | 13,84 | 24,13 |
| Вода Excel, м³ | 71,28 | 335,52 |
| Вода + сухотруб, м³ | 85,12 | 359,65 |
| Вода итог PDF, м³ | 85 | 359,42 |
| ПО по формулам Excel, м³ | **2,328** | **1,740** |
| ПО напечатано в PDF, м³ | **2,326** | **1,730** |

Нельзя автоматически изменять Excel-формулы ради совпадения с PDF.
Причины несовпадения подлежат уточнению ЭФЭР: исходные объёмы, округление/промежуточные значения, опечатки.

## Линейные потери (методика в PDF)

`Δh [МПа] = Q² × L / (100 × Кт)` при Q в л/с, L в м; Кт как в таблице PDF. Проверочный участок 40 л/с, 1,9 м, Кт 1429: Δh ≈ 0,0213 МПа.

**Это изолированная формула.** Расчёт полных гидравлических трасс, местных потерь, расходораспределения, баллистики струй и требуемого напора **в интерфейсе v0.1 не реализован**.

## BIM объёмы

Расчёт геометрического объёма: `V = π × (Dвн/1000)² / 4 × L` при Dвн в мм и L в м.
Извлечение `PipeInsideDiameter` из API необходимо проверить на реальной Renga-модели: единицы, наличие значения, доступность на экземпляре/стиле. Прототип намеренно отвергает явно неправдоподобные значения. Нельзя автоматически заменять **Dвн** условным проходом **Ду**.

Неизвестно, к каким трубам модели относится Wтр; объём всех труб не подставляется в Wтр. Объём сухотруба вводится отдельно либо по явному подтверждению пользователя.
