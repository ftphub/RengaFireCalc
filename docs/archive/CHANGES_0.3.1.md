# FireCalc v0.3.1 — UI patch (21.10.2026)

Причина: у пользователя 720p; окно 1320×810 и DockPanel v0.3.0 вытесняли таблицу и нижние действия. Исправлено без переписывания расчётной части.

- Адаптация габаритов окна к SystemParameters.WorkArea; 1100×640, минимум 620×360.
- Перекомпоновка гидравлики: источник → таблица → настройки → результаты; независимая вертикальная прокрутка страницы и таблицы.
- Прокрутка для перечня труб, исходных параметров, результатов и журнала.
- Компактный визуальный стиль macOS-inspired, стандартное WPF-окно Windows.
- Без изменений API-взаимодействия с Renga, формул, валидации и экспорта.

## Проверка

- XAML корректный XML, все x:Name и обработчики существуют.
- Необходимо пересобрать Release x64 в Visual Studio и протестировать UI при 1280×720 / Windows 125–150%.
