# Исправление Renga FireCalc v0.1.1 — 20.10.2026

## Диагностика по логу пользователя

- `FireCalc.Core`: сборка успешна.
- `FireCalc.Tests`: сборка успешна, однако выполнение тестов в логе не показано.
- `FireCalc.Plugin`: четыре ошибки в `ExcelExporter.cs` на строках 39 и 69.

## Исправлено

Добавлена директива:

```csharp
using System.IO;
```

в `FireCalc.Plugin/ExcelExporter.cs` до объявления пространства имён.

Это предоставляет `FileStream`, `FileMode`, `FileAccess`, `StreamWriter`.

## Отдельное предупреждение NuGet

В начале лога есть ошибка восстановления NuGet-метаданных `FireCalc.Core`. Однако оба проекта скомпилировались, поэтому причина не установлена. Если повторится, пришлите подробные сообщения из **Список ошибок → Сборка / NuGet** и вывод `dotnet restore FireCalc.sln`.

## Повторный тест на Windows

1. Распакуйте обновлённый ZIP в новую папку.
2. Откройте `FireCalc.sln` в Visual Studio.
3. Выберите `Release | x64` и выполните `Сборка → Пересобрать решение`.
4. Из консоли, если удалось собрать: `dotnet run --project FireCalc.Tests\FireCalc.Tests.csproj -c Release`.
5. Пришлите полный лог повторной сборки и теста; лишь после этого устанавливайте DLL в Renga и проверяйте запуск на копии проекта.

**Примечание:** полная сборка и выполнение в Renga на данном этапе не подтверждены.
