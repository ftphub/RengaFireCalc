# FireCalc v0.1.4 — исправление чтения внутреннего диаметра

Дата: 21.10.2026.

## Почему в v0.1.3 у всех труб был статус «Нет внутреннего диаметра»

Renga SDK 9.3 (API 2.50) сообщает, что для объектов Pipe доступен параметр `Renga.Parameters.PipeStyleId`, а `Renga.Parameters.PipeInsideDiameter` относится к сущности `PipeStyle`. `ModelBridge` ошибочно запрашивал `PipeInsideDiameter` только у экземпляра трубы.

## Изменения

1. `ModelBridge.ReadPipes()` запрашивает диаметр сначала у объекта (на случай специальных экземпляров), затем по `PipeStyleId` — у `Project.PipeStyles.GetById(styleId)` (через `IParameterContainer`).
2. Невычислимые диаметры остаются пустыми, не угадываются по имени трубы. Колонка «Источник Dвн» сообщает источник или проблему.
3. Суммарный объём и поле сухотруба отображаются с 8 знаками после запятой, чтобы маленькие диаметры не давали визуальный ноль. В XLSX остаётся полная точность `double`.
4. Добавлен контрольный тест геометрического объёма на 10 сегментах пользовательского IFC.

## Ожидаемые данные из IFC «пожаркаНовый проект.ifc»

- 6 труб PPR PN20 20×3,4, фактический внутренний диаметр 13,2 мм;
- 4 трубы ВЧШГ 50, фактический внутренний диаметр 50 мм;
- суммарная длина 16,7782756856 м;
- суммарный объём десяти труб 0,009862241136 м³ ≈ 9,86 л.

IFC доказывает наличие этих свойств **в экспортированной IFC-модели**, но загрузка значений через COM API после исправления требует реальной проверки в Renga.

## Проверка

1. Закрыть Renga. Собрать обновлённый `FireCalc.sln` в Release / x64.
2. Скопировать всё из `_build/FireCalc/` в `C:\Program Files\Renga Professional\Plugins\FireCalc`, заменив прежние файлы.
3. Запустить Renga с тем же тестовым проектом. Нажать `Прочитать трубы Renga`.
4. Ожидается 10 строк, 10/10 полных, Dвн=13,2 мм для 6 PPR и 50 мм для 4 ВЧШГ. Сумма 0,00986224 м³.
5. Экспортировать XLSX; проверить лист «Трубы Renga», колонка «Источник Dвн».
6. **Не нажимать «Объём труб → сухотруб» как инженерное значение без выбора системы. Не записывать свойства в рабочий проект.**

При несоответствии прислать вкладку «Трубы / диагностика» и `AecApp.log`.

## Ограничения

Проверка компиляции и COM-вызовов под Windows не выполнялась в этой среде. Исходники требуют локальной сборки. Разработка плагина не обеспечивает валидированный гидравлический расчёт и не является расчётом по применяемым противопожарным нормам.
