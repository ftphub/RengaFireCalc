# FireCalc v0.5.0 — изменения, 22.10.2026

Основа: FireCalc v0.4.0, реально запущенный пользователем в Renga 9.3. Новая версия **требует компиляции и испытаний Windows**.

## Новое

1. Подсказки при наведении на подписи исходных параметров и их поля ввода, заголовки расчётных таблиц, строки результатов, кнопки. Определения, единицы, назначение и формулы взяты из переданных Excel и РУП.Т; сторонние универсальные нормы не подставляются.
2. Вкладка **«Подсказки и формулы»**: 61 статья по запасам, гидравлике, геометрии труб и объектам Renga, поиск по терминам и тексту.
3. Вкладка «Связность / маршруты» дополнена read-only диагностикой **IEntityWithPorts/IPort** с выводом ID порта и его ConnectedRouteId. Соединения Renga через оборудование не считаются автоматически доказательством протока и не влияют молча на расчёт.
4. Ввод сценария насосов (не задан, рабочий+резервный, оба рабочие, ручной) и идентификаторов насосов. Реализована только декларация сценария; реальная характеристика Q–H, параллельная работа, NPSH, насосная автоматика не рассчитываются.
5. Исправлена ошибка компиляции `List<int>.Length` → `List<int>.Count` в NetworkTopology.
6. Сохранены разделы v0.4: расчёт ПО по Excel, ручная гидравлика, чтение труб и запись объёмов, экспорт, диагностика IRouteParams, поиск пути и баланс расходов по простому дереву.

## Ограничения

- **Не утверждается**, что все элементы тестового `.rnp` автоматически образуют одну гидравлическую систему: API маршрутов показывает 2 компоненты, IFC — одну физическую сеть по связям портов. Это разные уровни представления, необходима проверка оборудования и фитингов.
- Портовая диагностика помогает найти соседние маршруты, но не корректирует автоматически их топологию, не устанавливает направление движения жидкости.
- В ручном расчёте сопротивления Кт, потери оборудования и расходы вводятся и подтверждаются инженером.
- Не предназначен для выпуска безопасной рабочей документации без инженерного подтверждения.
