# Испытания FireCalc v0.3.1 — экран 720p

### Сборка и загрузка

1. Release / x64, Visual Studio 2022. Не устанавливать до успешной сборки.
2. Проверить заголовок окна `Renga FireCalc 0.3.1 — ЭФЭР`.
3. При разрешении 1280×720 и масштабе 100%, затем при 125% (при возможности — 150%) убедиться, что нижняя строка состояния видима, окно не выходит за границы экрана.

### Первая вкладка — запасы

1. Примеры `Окрасочный` / `Ремонтный` загружаются, все поля доступны прокруткой слева.
2. Результаты таблицы справа прокручиваются; Excel выгружается; значения совпадают с v0.3.0 (окрасочный 2.328 м³, ремонтный 1.740 м³ — по используемым формулам Excel).
3. Проверить изменение времени тушения и перерасчёт.

### Вкладка «Гидравлика / трасса»

1. Нажать `ЭФЭР: окрасочный`; в верхней части должны быть видны выбор режима и начало таблицы участков.
2. Прокрутить **правый ползунок страницы** вниз до блока параметров и кнопки `Рассчитать трассу`, а затем до итогов; убедиться, что ничего не обрезано.
3. Прокрутить таблицу внутри карточки на 8–20 строках; при узком окне использовать горизонтальную прокрутку внутри таблицы.
4. Для `ЭФЭР: ремонтный` проверить ~23.754 м потерь и ~104.237 м расчётного напора.
5. Нажать `Загрузить трубы Renga` и проверить сброс демопараметров в 0; без подтверждения пути расчёт должен блокироваться.

### Вкладка «Трубы / Renga»

1. Обновить трубы; таблица скроллится отдельно, вся страница — по правому ползунку.
2. Расчётный объём 11 тестовых труб должен остаться прежним, если геометрия не изменилась.
3. Запись свойств проверять только в копии проекта.

### Ограничения проверки

Исходники проверены статически: XAML, имена, обработчики и неизменность расчётного ядра. Компиляцию/запуск WPF в Windows необходимо подтвердить пользователю.
