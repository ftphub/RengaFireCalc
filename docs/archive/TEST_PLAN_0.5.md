# План испытаний FireCalc v0.5.0 под Windows / Renga 9.3

1. Создать резервную копию `C:\Program Files\Renga Professional\Plugins\FireCalc` вне папки Plugins.
2. В Visual Studio 2026 открыть `FireCalc.sln`; Release / x64; **Пересобрать решение**. Ошибок компиляции быть не должно.
3. Запустить `dotnet run --project FireCalc.Tests/FireCalc.Tests.csproj -c Release`. Последняя строка: `ALL v0.5 CORE TESTS PASSED.` При проблемах сначала исправить исходники, не устанавливать.
4. Скопировать содержимое `_build/FireCalc/` в папку установленного плагина (при закрытой Renga) и запустить Renga. В заголовке должна быть версия **0.5.0**.
5. Проверить подсказки: наведение на `Wтр`, `Q, л/с`, `Кт`, `v, м/с`, `Δh, м` и строку `Общий запас ПО, W`. Показать скриншоты хотя бы двух.
6. На вкладке `Подсказки и формулы` проверить поиск `Wmin`, затем `напор`, затем очистить строку поиска.
7. Вкладка `Запасы воды и ПО`: окрасочный, нажать `Рассчитать`: W=**2,328 м³**; ремонтный: W=**1,740 м³**. Это расчёт по Excel, он может отличаться от PDF ЭФЭР.
8. Вкладка `Трубы / Renga`: на ранее проверенной модели 11 труб подтвердить общий объём **0,13605473 м³**, но не подставлять его в Wтр.
9. На новом тестовом проекте с резервуаром, двумя насосами и 2 потребителями открыть `Связность / маршруты` → `Проверить маршруты Renga` (в v0.4 было 4 маршрута, 2 группы по маршрутам) → `Прочитать порты оборудования`. Зафиксировать число прочитанных портов и сообщения. Данные никуда не записываются.
10. В сценарии насосов оставить `Не задан` и нажать `Сценарий насосов`. Затем выбрать `Рабочий + резервный`, ввести два валидных ID (только демонстрация). Ожидается предупреждение, что автоматика и Q–H не проверены. Проверить некорректный повтор ID — должно быть предупреждение.
11. Проверить прежние экспорты XLSX и CSV и ручную гидравлику. Сверить, что сценарий насосов **не влияет на числа без данных Q–H**.
12. Проверить работу на разрешении 1280 × 720: прокрутка вкладки, таблиц и доступность кнопок, в том числе вкладки справки.

При любой ошибке пришлите лог сборки и AecApp.log Renga. **Нельзя заявлять о готовой Windows-сборке до выполнения этих пунктов.**
