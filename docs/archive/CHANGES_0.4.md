# FireCalc v0.4.0 — перечень изменений и уровни готовности

## Унаследовано из v0.3.1 — проверено пользователем в Renga 9.3
- Загрузка модуля, WPF-интерфейс и прокрутка на 720p.
- Ручной расчёт запасов воды и пенообразователя по Excel ЭФЭР.
- Два демонстрационных гидравлических расчёта по RUP.T.
- Получение геометрии труб (включая внутренний диаметр через стиль), запись пользовательских свойств.
- Отчёты Excel и проверка 11 объектов (0,13605473 м³).

## Новые исходники v0.4 — НЕ проверены в Windows/Renga
- `FireCalc.Core/NetworkTopology.cs` — граф связности, компоненты, циклы, однозначный путь; расчёт Q дерева по заданным спросам.
- `FireCalc.Plugin/ModelBridge.cs` — чтение Route/IRouteParams/FlowSegmentPlacement из SDK 2.50.
- `FireCalc.Plugin/NetworkUi.cs` — обработчики новой вкладки, предупреждения, передача пути и Q в гидравлику, экспорт CSV.
- `FireCalc.Plugin/MainWindow.xaml` — вкладка «Связность / маршруты», колонка скорости v и точности Δh.
- `FireCalc.Plugin/MainWindow.xaml.cs` — скорость потока и ориентировочное предупреждение при v > 3 м/с.
- `FireCalc.Core/HydraulicRoute.cs` и `ExcelExporter.cs` — внутренний диаметр и скорость включены в детальную ведомость гидравлики XLSX, если эти данные доступны в модели.
- `FireCalc.Tests/Program.cs` — тесты: компоненты графа, путь, возврат, дерево Q, неполные потребители, кольцо, несвязность, пустые PipeIds, смешение стилей, скорость и неверные диаметры.
- `BUILD_AND_DEPLOY.ps1` — запуск тестов → Windows Release/x64 → ZIP собранных файлов → резервная копия при `-Install`.

## Статическая проверка в среде разработки
- XML/XAML/CSProj/RNDESC проходят XML-парсер.
- Все имена обработчиков из XAML найдены в исходниках C#.
- Баланс скобок в C# проверен лексером.
- Архив исходников прошёл CRC-проверку.
- **Нет .NET SDK, MSBuild, Windows и Renga:** реальные C# тесты, DLL и загрузка через COM API здесь НЕ подтверждены.

## Критические условия применения
- Нельзя приравнивать пересечение геометрии к гидравлическому соединению.
- Кандидат пути получается по Renga Route, не по геометрическим пересечениям.
- Расходы рассчитываются по дереву только при одном источнике и введённых Q всех конечных потребителей.
- Кт, местные потери, напор потребителя и оборудование не заполняются без данных инженера.
- Нормативная проверка противопожарных систем, увязка кольцевых сетей и подбор насоса НЕ реализованы.
- Суммарный объём всех труб в модели не равен ёмкости отдельной системы без инженерного подтверждения.
