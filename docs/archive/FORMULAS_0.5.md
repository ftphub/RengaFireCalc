# Формулы и пояснения

Источник формул запасов — Excel ЭФЭР. Источник коэффициентной формулы гидравлики — приложение «Гидравлический расчёт» к РУП.Т (стр. 21–22 переданного PDF). Применять только после верификации инженером.

- Вода на тушение: `Vт = Qр · t · 60 · (1 - c/100) / 1000`, м³.
- Вода на охлаждение: `Vо = Qо · tо · 60 / 1000`, м³.
- Рабочий запас ПО: `Wраб = Qр · t · 60 · (c/100) / 1000`, м³.
- Резерв: `Wрез = Wраб` (допущение шаблона).
- Поправка дозирования: `Wкомп = 0,2 · (Wраб + Wрез)`.
- Испытания: `Wисп = 0,1 · Wраб`.
- Минимальный уровень: `Wmin = ROUND(0,2 · (Wраб + Wрез + Wкомп + Wисп + Wтр), 3)`.
- Общий запас ПО: `W = Wраб + Wрез + Wкомп + Wисп + Wтр + Wmin`.
- Геометрический объём трубы: `V = π · (Dвн / 1000)^2 · L / 4`, м³, где Dвн задан в мм.
- Скорость: `v = (Q/1000) / (π · (Dвн/1000)^2 / 4)`, м/с.
- Линейные потери ЭФЭР: `Δh[МПа] = Q² · L / (100 · Кт)`; далее конверсия в метры водного столба, методика требует проверенных Кт.
- Требуемый напор выбранной трассы: `Hтреб = ∑hлин + hмест + hобор + Hпотр + Δz`.

`Wтр` (вместимость трубы пенообразователя по методике) и объём сухотруба — **не взаимозаменяемые величины**. Сумма всех труб BIM не равна автоматически ни одной из них.

**ВНИМАНИЕ**: исходный PDF содержит небольшие расхождения между суммами промежуточных данных и напечатанными итогами. Значения расчётов FireCalc не следует искусственно приводить к значениям PDF без согласования методики.
