# Ручные испытания FireCalc v0.3.0 на Renga 9.3

Проводить только на **копии** проекта. Результаты и ошибки сохранять в скриншотах и `AecApp.log`.

1. **Компиляция:** Visual Studio 2022 → Release x64 → три проекта без ошибок. Тесты `dotnet run --project .\FireCalc.Tests\FireCalc.Tests.csproj -c Release` → `ALL TESTS PASSED`.
2. **Загрузка:** окно имеет заголовок `Renga FireCalc 0.3.0`, четыре вкладки. Другие модули работают, критических записей о FireCalc в `AecApp.log` нет.
3. **Запасы, окрасочный:** вкладка 1 → пример окрасочного → рассчитать: `W=2,328 м³`, `Vводы=71,28 м³`, `Vводы + сухотруб=85,12 м³`. Экспорт XLSX содержит те же цифры.
4. **Запасы, ремонтный:** `W=1,740 м³`; числовые результаты сверить с прежним экспортом.
5. **Защита от устаревшего экспорта:** после расчёта изменить время тушения → кнопка экспорта должна отключиться до повторного «Рассчитать запасы».
6. **Гидравлика демо:** вкладка 2 → окрасочный → расчёт: трассовые потери около 21,423 м; суммарный напор около 101,906 м. Ремонтный: около 23,754 м и 104,237 м. Экспорт формирует две вкладки.
7. **Сброс данных:** после демо ремонтного цеха нажать «Прочитать трубы из Renga» — местные %, оборудование, напор у потребителя, отметки становятся 0, ни одна труба не отмечена, Q/Кт пусты, подтверждение снято, экспорт отключён. НЕ должно оставаться 17,049, 61,183, 19,3 и 20.
8. **Защита расчёта:** выбрать одну трубу, ввести Q и Кт, но не подтверждать исходные данные → расчёт запрещён с понятным сообщением. После подтверждения без Q или Кт → ошибка конкретного участка. После ввода Q и Кт → условный расчёт, без слова «требуемый напор всей установки».
9. **Изменение гидравлики:** после успешного расчёта изменить Q или любой общий параметр → экспорт выключается до повторного расчёта.
10. **Трубы:** вкладка 3 → прочитать Renga: 11 сегментов тестовой модели, включая ID 100042 и `Dвн=73,4 мм` (если именно этот проект открыт). Геометрический объём всей модели ≈ 0,13605473 м³, трубы можно просматривать и в литрах.
11. **Защита от изменений:** после чтения труб изменить длину одного участка в копии проекта, нажать «Записать объёмы в Renga» — операция должна быть отменена до повторного чтения модели.
12. **Запись:** в отдельной копии проекта проверить запись пользовательского свойства геометрического объёма для трубы ID 100042: примерно 0,12619249 м³ (в свойствах из-за округления может отображаться 0,13). Повторно открыть проект, проверить сохранность.

**Не принимать:** получение «полного напора установки» после ввода расхода/Кт для одной трубы как доказательство корректности всей системы. Не выдавать демо ЭФЭР за воспроизведение непрерывной сети.
