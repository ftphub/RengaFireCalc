# FireCalc 0.5.1 — копирование ID

- Копирование ID маршрута, начального и конечного объектов выбранной строки.
- Кнопки подстановки начального/конечного объекта для поиска пути и кандидата источника в расчёт расходов дерева.
- Копирование ID объекта/маршрута из таблицы портов и вставка выбранного объекта в поля начала/конца пути либо кандидата источника.
- Кнопка добавления выбранного объекта «Насос» в список ID сценария, без дублей и без назначения рабочего режима.
- Копирование ID трубы из таблиц геометрии и гидравлики.
- Защита от отсутствующего выделения, нулевого ID, ошибки буфера обмена, дублей.
- Расчётная логика и работа с Renga API не менялись.

## Проверка в Renga
1. В «Связность / маршруты» нажать «Проверить маршруты Renga» и выделить маршрут.
2. Копировать ID маршрута и оба конца; проверить вставкой в Блокнот.
3. «От → начало пути», «К → конец пути» — поля должны заполниться корректными ID.
4. «Прочитать порты оборудования»; выделить порт насоса и нажать «Добавить ID насоса из строки»; проверить что повторное нажатие не создаёт дублей.
5. На вкладке «Трубы / Renga» выбрать строку и скопировать ID.
6. Проверить резервные расчёты, экспорт XLSX и чтение сети на эталонном проекте.
