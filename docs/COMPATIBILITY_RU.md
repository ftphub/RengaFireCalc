# Совместимость

| Компонент | Версия | Статус |
|:--|:--|:--|
| Renga Professional | 9.3 | Пользователь подтвердил запуск v0.5.1 и чтение модели |
| Renga API | 2.50 | Используется проектом и дескриптором |
| Windows | x64 | Пользовательские испытания на Windows |
| .NET | 8 (WPF) | Целевой runtime плагина |
| Visual Studio | 2026 | Пользователь успешно собирал и запускал предыдущие версии, в т.ч. v0.5.1 |
| Visual Studio | 2022 | Проект рассчитан на MSBuild с .NET 8; отдельная сборка v0.5.1 не подтверждена |
| Renga 9.2 или более ранние версии | — | Не испытаны |
| Linux / Wine | — | Не проверено и не заявляется |
| Работа без подключения к интернету | Локальная расчётная логика | Встроенного облачного расчётного сервиса нет |

> Для сборки Renga COM interop нужны оригинальные файлы SDK в `sdk/`. Они исключены из репозитория.
